## 🍓 Featured Backend Projects

### 🛒 [위굴 Backend](https://github.com/SaGongSa-404/404_BE)

> 쇼핑 링크 수집과 알림 기능을 제공하는 서비스의 Spring Boot 백엔드

`Java 21` `Spring Boot 3.5` `JPA` `Flyway` `PostgreSQL` `Testcontainers` `Docker` `FCM`

- Flyway 마이그레이션과 JPA 엔티티를 함께 검증하는 DB 스키마 기준선 구축
- Testcontainers 기반 PostgreSQL 통합 테스트와 JaCoCo 커버리지 구성
- 사용자별 동시 작업 수, 재시도 횟수와 stale 작업 복구를 고려한 비동기 작업 환경
- FCM 자격 증명을 저장소 밖에서 주입하는 환경별 푸시 설정
- Docker Compose 기반 애플리케이션·PostgreSQL 실행 환경 표준화

<br/>

### 💌 [Dongle Backend](https://github.com/Dongle-2026/Dongle-BE)

> 청년을 위한 정보 서비스의 Spring Boot 백엔드

`Java 17` `Spring Boot 3.4` `Security` `OAuth2` `JWT` `QueryDSL` `Redis` `pgvector`

- JWT와 OAuth2 Client를 활용할 수 있는 인증 기반 구성
- JPA, QueryDSL, PostgreSQL을 이용한 데이터 접근 환경
- Redis와 pgvector를 활용할 수 있는 데이터 처리 기반
- WebClient 외부 API 연동과 Jsoup 콘텐츠 수집 구성
- OpenAPI 문서화와 개발·테스트·운영별 Docker Compose 환경 분리

> 프로젝트의 구체적인 담당 기능과 트러블슈팅 기록을 계속 보강하고 있습니다. 🌱
